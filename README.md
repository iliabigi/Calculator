# Calculator
**The Final project of TOP foundation course.**

This a feature-rich calculator which allows you to do your calculations as fast as possible. [*Use the calculator.*](https://iliabigi.github.io/Calculator/)

## Keybinds
- C -> Clear everything
- Backspace -> undo your last entry
- Enter -> '=' button
  
Other numbers and operators use the same buttons as the keyboard.
